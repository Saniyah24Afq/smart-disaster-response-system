# 🚨 Smart Disaster Response and Resource Management System

## 📌 Project Overview

The Smart Disaster Response and Resource Management System is a web-based platform designed to improve disaster reporting, emergency response, resource management, and coordination between citizens, administrators, and response teams.

The system provides a centralized platform where citizens can report emergencies, administrators can verify and manage incidents, response teams can handle assigned emergencies, and resources can be efficiently allocated to affected areas.

---

## 🎯 Objectives

- Provide a platform for citizens to report disasters.
- Enable administrators to verify and manage disaster incidents.
- Manage emergency resources efficiently.
- Assign response teams to disaster incidents.
- Track disaster and response status.
- Provide a centralized disaster management dashboard.
- Improve coordination between citizens and emergency response teams.
- Implement Agile Software Development practices.
- Implement DevOps practices including CI/CD, Docker, testing, and deployment.

---

## 👥 User Roles

### 👤 Citizen

- Register and login.
- Report disasters.
- Provide disaster location and description.
- View submitted reports.
- Track report status.

### 🛡️ Administrator

- Manage disaster reports.
- Verify or reject reports.
- Manage emergency resources.
- Allocate resources.
- Manage response teams.
- Assign teams to incidents.
- Monitor disaster statistics.
- View the main dashboard.

### 🚑 Response Team

- Login to the response dashboard.
- View assigned incidents.
- Update incident status.
- Request resources.
- Mark incidents as completed.
